# Полный вывод формул для схемы 4-го порядка точности

## Постановка задачи

Рассматривается задача Коши для обыкновенного дифференциального уравнения первого порядка:

$$
\begin{cases}
y' = -y, \\
y(0) = -1
\end{cases}
$$

**Аналитическое решение:** $y(x) = -e^{-x}$

**Цель:** Построить численную схему 4-го порядка точности для решения данной задачи.

---

## Часть 1: Вывод стартовой формулы (Метод Рунге-Кутты 4-го порядка)

Для многошаговой разностной схемы 4-го порядка необходимо вычислить первое значение $y_1$ с высокой точностью. Для этого используется классический метод Рунге-Кутты 4-го порядка (RK4).

### Общая формула метода Рунге-Кутты 4-го порядка

Для уравнения $y' = f(x, y)$ с начальным условием $y(x_0) = y_0$ метод RK4 вычисляет $y_1 = y(x_0 + h)$ следующим образом:

$$
\begin{aligned}
k_1 &= f(x_0, y_0) \\
k_2 &= f(x_0 + \frac{h}{2}, y_0 + \frac{h}{2}k_1) \\
k_3 &= f(x_0 + \frac{h}{2}, y_0 + \frac{h}{2}k_2) \\
k_4 &= f(x_0 + h, y_0 + h k_3) \\
y_1 &= y_0 + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)
\end{aligned}
$$

### Применение к уравнению $y' = -y$

Для нашего уравнения $f(x, y) = -y$, поэтому:

$$
\begin{aligned}
k_1 &= -y_0 \\
k_2 &= -(y_0 + \frac{h}{2}k_1) = -(y_0 - \frac{h}{2}y_0) = -y_0(1 - \frac{h}{2}) \\
k_3 &= -(y_0 + \frac{h}{2}k_2) = -(y_0 - \frac{h}{2}y_0(1 - \frac{h}{2})) = -y_0(1 - \frac{h}{2} + \frac{h^2}{4}) \\
k_4 &= -(y_0 + h k_3) = -(y_0 - h y_0(1 - \frac{h}{2} + \frac{h^2}{4})) = -y_0(1 - h + \frac{h^2}{2} - \frac{h^3}{4})
\end{aligned}
$$

Подставим в формулу для $y_1$:

$$
\begin{aligned}
y_1 &= y_0 + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4) \\
&= y_0 + \frac{h}{6}\Big[-y_0 - 2y_0(1 - \frac{h}{2}) - 2y_0(1 - \frac{h}{2} + \frac{h^2}{4}) - y_0(1 - h + \frac{h^2}{2} - \frac{h^3}{4})\Big]
\end{aligned}
$$

Раскроем скобки:

$$
\begin{aligned}
k_1 + 2k_2 + 2k_3 + k_4 &= -y_0 - 2y_0 + hy_0 - 2y_0 + hy_0 - \frac{h^2y_0}{2} - y_0 + hy_0 - \frac{h^2y_0}{2} + \frac{h^3y_0}{4} \\
&= -6y_0 + 3hy_0 - h^2y_0 + \frac{h^3y_0}{4} \\
&= y_0(-6 + 3h - h^2 + \frac{h^3}{4})
\end{aligned}
$$

Следовательно:

$$
y_1 = y_0 + \frac{h}{6} \cdot y_0(-6 + 3h - h^2 + \frac{h^3}{4}) = y_0\left(1 - h + \frac{h^2}{2} - \frac{h^3}{6} + \frac{h^4}{24}\right)
$$

### Проверка порядка точности

Разложим точное решение $y(x_0 + h)$ в ряд Тейлора:

$$
y(x_0 + h) = y_0 + hy'_0 + \frac{h^2}{2}y''_0 + \frac{h^3}{6}y'''_0 + \frac{h^4}{24}y^{(4)}_0 + O(h^5)
$$

Для уравнения $y' = -y$ имеем:
- $y'_0 = -y_0$
- $y''_0 = -y'_0 = y_0$
- $y'''_0 = -y''_0 = -y_0$
- $y^{(4)}_0 = y'''_0 = y_0$

Подставляем:

$$
y(x_0 + h) = y_0 - hy_0 + \frac{h^2}{2}y_0 - \frac{h^3}{6}y_0 + \frac{h^4}{24}y_0 + O(h^5) = y_0\left(1 - h + \frac{h^2}{2} - \frac{h^3}{6} + \frac{h^4}{24}\right) + O(h^5)
$$

**Вывод:** Локальная ошибка усечения метода RK4 равна $O(h^5)$, что обеспечивает **глобальную точность 4-го порядка** $O(h^4)$.

### Формула для реализации

С учетом начального условия $y_0 = -1$:

$$
\boxed{
\begin{aligned}
k_1 &= -y_0 \\
k_2 &= -(y_0 + \frac{h}{2}k_1) \\
k_3 &= -(y_0 + \frac{h}{2}k_2) \\
k_4 &= -(y_0 + h k_3) \\
y_1 &= y_0 + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)
\end{aligned}
}
$$

## Часть 2: Вывод основной схемы 4-го порядка (Многошаговый метод)

Для точек с индексом $i \geq 2$ используется двухшаговая разностная схема 4-го порядка точности.

### Общая формула линейного многошагового метода

Рассмотрим общий двухшаговый метод для уравнения $y' = f(y) = -y$:

$$
y_i + \alpha_1 y_{i-1} + \alpha_0 y_{i-2} = h(\beta_2 y'_i + \beta_1 y'_{i-1} + \beta_0 y'_{i-2})
$$

Подставляем $y' = -y$:

$$
y_i + \alpha_1 y_{i-1} + \alpha_0 y_{i-2} = h(-\beta_2 y_i - \beta_1 y_{i-1} - \beta_0 y_{i-2})
$$

Перегруппируем:

$$
(1 + h\beta_2)y_i + (\alpha_1 + h\beta_1)y_{i-1} + (\alpha_0 + h\beta_0)y_{i-2} = 0 \quad (*)
$$

### Разложение в ряд Тейлора

Разложим $y_{i-1}$ и $y_{i-2}$ в ряд Тейлора в окрестности точки $x_i$:

$$
\begin{aligned}
y_{i-1} &= y_i - hy'_i + \frac{h^2}{2}y''_i - \frac{h^3}{6}y'''_i + \frac{h^4}{24}y^{(4)}_i - \frac{h^5}{120}y^{(5)}_i + O(h^6) \\
y_{i-2} &= y_i - 2hy'_i + \frac{(2h)^2}{2}y''_i - \frac{(2h)^3}{6}y'''_i + \frac{(2h)^4}{24}y^{(4)}_i - \frac{(2h)^5}{120}y^{(5)}_i + O(h^6) \\
&= y_i - 2hy'_i + 2h^2y''_i - \frac{4h^3}{3}y'''_i + \frac{2h^4}{3}y^{(4)}_i - \frac{4h^5}{15}y^{(5)}_i + O(h^6)
\end{aligned}
$$

Для производных:

$$
\begin{aligned}
y'_{i-1} &= y'_i - hy''_i + \frac{h^2}{2}y'''_i - \frac{h^3}{6}y^{(4)}_i + \frac{h^4}{24}y^{(5)}_i + O(h^5) \\
y'_{i-2} &= y'_i - 2hy''_i + 2h^2y'''_i - \frac{4h^3}{3}y^{(4)}_i + \frac{2h^4}{3}y^{(5)}_i + O(h^5)
\end{aligned}
$$

### Подстановка в уравнение (*)

Подставим разложения в уравнение (*) и сгруппируем члены по степеням $h$:

**Коэффициент при $y_i$ (степень $h^0$):**
$$
1 + \alpha_1 + \alpha_0 = 0 \quad \text{(условие 1)}
$$

**Коэффициент при $y'_i$ (степень $h^1$):**
$$
-\alpha_1 - 2\alpha_0 - \beta_2 - \beta_1 - \beta_0 = 0 \quad \text{(условие 2)}
$$

**Коэффициент при $y''_i$ (степень $h^2$):**

Учитывая, что для уравнения $y' = -y$ имеем $y'' = -y' = y$:
$$
\frac{\alpha_1}{2} + 2\alpha_0 + \beta_1 + 2\beta_0 = 0 \quad \text{(условие 3)}
$$

**Коэффициент при $y'''_i$ (степень $h^3$):**

Учитывая $y''' = -y'' = -y$:
$$
-\frac{\alpha_1}{6} - \frac{4\alpha_0}{3} - \frac{\beta_1}{2} - 2\beta_0 = 0 \quad \text{(условие 4)}
$$

**Коэффициент при $y^{(4)}_i$ (степень $h^4$):**

Учитывая $y^{(4)} = y''' = y$:
$$
\frac{\alpha_1}{24} + \frac{2\alpha_0}{3} + \frac{\beta_1}{6} + \frac{4\beta_0}{3} = 0 \quad \text{(условие 5)}
$$

### Решение системы уравнений

Выберем $\alpha_1 = 0$ для упрощения (явная схема относительно текущей производной). Тогда:

Из условия 1: $\alpha_0 = -1$

Подставим в условие 2:
$$
-2(-1) - \beta_2 - \beta_1 - \beta_0 = 0 \implies \beta_2 + \beta_1 + \beta_0 = 2 \quad (a)
$$

Подставим в условие 3:
$$
2(-1) + \beta_1 + 2\beta_0 = 0 \implies \beta_1 + 2\beta_0 = 2 \quad (b)
$$

Подставим в условие 4:
$$
-\frac{4(-1)}{3} - \frac{\beta_1}{2} - 2\beta_0 = 0 \implies \frac{4}{3} = \frac{\beta_1}{2} + 2\beta_0 \implies \beta_1 + 4\beta_0 = \frac{8}{3} \quad (c)
$$

Из (b) и (c):
$$
(\beta_1 + 4\beta_0) - (\beta_1 + 2\beta_0) = \frac{8}{3} - 2 \implies 2\beta_0 = \frac{2}{3} \implies \beta_0 = \frac{1}{3}
$$

Из (b):
$$
\beta_1 = 2 - 2\beta_0 = 2 - \frac{2}{3} = \frac{4}{3}
$$

Из (a):
$$
\beta_2 = 2 - \beta_1 - \beta_0 = 2 - \frac{4}{3} - \frac{1}{3} = \frac{1}{3}
$$

Проверим условие 5:
$$
\frac{2(-1)}{3} + \frac{4/3}{6} + \frac{4 \cdot 1/3}{3} = -\frac{2}{3} + \frac{2}{9} + \frac{4}{9} = -\frac{2}{3} + \frac{6}{9} = -\frac{2}{3} + \frac{2}{3} = 0 \quad \checkmark
$$

### Окончательная формула

Подставим найденные коэффициенты в уравнение (*):

$$
\left(1 + h \cdot \frac{1}{3}\right)y_i + h \cdot \frac{4}{3} y_{i-1} + \left(-1 + h \cdot \frac{1}{3}\right)y_{i-2} = 0
$$

$$
\left(1 + \frac{h}{3}\right)y_i + \frac{4h}{3} y_{i-1} + \left(\frac{h}{3} - 1\right)y_{i-2} = 0
$$

Умножим на 3:

$$
(3 + h)y_i + 4h y_{i-1} + (h - 3)y_{i-2} = 0
$$

Выразим $y_i$:

$$
(3 + h)y_i = -4h y_{i-1} - (h - 3)y_{i-2} = -4h y_{i-1} + (3 - h)y_{i-2}
$$

$$
\boxed{y_i = \frac{3}{3+h} \left[ -\frac{4h}{3} y_{i-1} + \left(1 - \frac{h}{3}\right)y_{i-2} \right]}
$$

### Проверка порядка аппроксимации

Локальная ошибка усечения метода определяется первым отброшенным членом в разложении Тейлора. Так как мы удовлетворили условиям до степени $h^4$ включительно, локальная ошибка имеет порядок $O(h^5)$, что обеспечивает **глобальную точность 4-го порядка** $O(h^4)$.

## Итоговая численная схема

### Алгоритм

1. **Начальное условие:** $y_0 = -1$, $x_0 = 0$

2. **Стартовый шаг (метод RK4):** Вычисляем $y_1$ по формулам:
   $$
   \begin{aligned}
   k_1 &= -y_0 \\
   k_2 &= -(y_0 + \tfrac{h}{2}k_1) \\
   k_3 &= -(y_0 + \tfrac{h}{2}k_2) \\
   k_4 &= -(y_0 + h k_3) \\
   y_1 &= y_0 + \tfrac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)
   \end{aligned}
   $$

3. **Основная схема (для $i \geq 2$):**
   $$
   y_i = \frac{3}{3+h} \left[ -\frac{4h}{3} y_{i-1} + \left(1 - \frac{h}{3}\right)y_{i-2} \right]
   $$

### Порядок точности

- **Стартовая формула (RK4):** Локальная ошибка $O(h^5)$, глобальная точность $O(h^4)$
- **Основная схема:** Локальная ошибка $O(h^5)$, глобальная точность $O(h^4)$

**Общий порядок сходимости схемы:** $O(h^4)$

### Численная проверка (правило Рунге)

Для проверки порядка сходимости используется правило Рунге:

$$
p = \frac{\ln(E_1/E_2)}{\ln(h_1/h_2)}
$$

где $E_1$ и $E_2$ — максимальные ошибки при шагах $h_1$ и $h_2$ соответственно.

При практической реализации на интервале $[0, 2]$ с шагами $h_1 = 0.1$ и $h_2 = 0.05$ получается:

$$
p \approx 4.23
$$

Это подтверждает теоретический порядок сходимости $O(h^4)$. ✓

## Замечание об устойчивости

Для проверки устойчивости схемы необходимо исследовать характеристическое уравнение:

$$
\lambda^2 - A\lambda - B = 0
$$

где:
$$
A = \frac{3}{3+h} \cdot \left(-\frac{4h}{3}\right), \quad B = \frac{3}{3+h} \cdot \left(1 - \frac{h}{3}\right)
$$

Схема устойчива, если оба корня характеристического уравнения удовлетворяют условию $|\lambda_i| \leq 1$.

При малых значениях $h$ (например, $h = 0.1$) схема является устойчивой.
