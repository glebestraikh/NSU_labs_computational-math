# Формулы для разностной схемы 4-го порядка

## Уравнение

Рассматривается дифференциальное уравнение:
$$ y' = -y $$
с начальным условием $y(0) = -1$.

## Разностная схема

Для нахождения численного решения используется многошаговая разностная схема 4-го порядка точности.

### 1. Начальный шаг (схема 3-го порядка)

Для вычисления второй точки $y_1$ (при $i=1$) используется специальная формула, обеспечивающая 3-й порядок точности, чтобы "разогнать" основную схему.

С учетом начального условия $y_0 = -1$:
$$ y_1 = \frac{3h - h^2 - 3}{h^2 + 3} $$

Или в общем виде (для произвольного $y_0$):
$$ y_1 = y_0 \frac{3 - 3h + h^2}{3 + h^2} $$

Эта формула применяется один раз для нахождения значения в узле $x_1 = x_0 + h$ и обеспечивает локальную ошибку $O(h^4)$.

### 2. Основная схема (4-й порядок)

Для всех последующих точек $y_i$ (при $i \ge 2$) используется следующая двухшаговая рекуррентная формула:

$$ y_i = \frac{3}{3+h} \left( -\frac{4}{3}h \cdot y_{i-1} + \left(1 - \frac{h}{3}\right) y_{i-2} \right) $$

Эту формулу можно также представить в виде:

$$ (3+h)y_i + 4h \cdot y_{i-1} - (3-h)y_{i-2} = 0 $$

Эта схема использует два предыдущих значения ($y_{i-1}$ и $y_{i-2}$) для вычисления следующего ($y_i$) и обеспечивает 4-й порядок аппроксимации $O(h^4)$.

## Вывод формул

### 1. Вывод основной схемы 4-го порядка

Будем искать численное решение уравнения $y' = -y$ в виде общего линейного двухшагового метода:

$$ y_i + \alpha_1 y_{i-1} + \alpha_0 y_{i-2} = h(\beta_2 y'_i + \beta_1 y'_{i-1} + \beta_0 y'_{i-2}) $$

Подставим $y' = -y$:

$$ y_i + \alpha_1 y_{i-1} + \alpha_0 y_{i-2} = h(-\beta_2 y_i - \beta_1 y_{i-1} - \beta_0 y_{i-2}) $$

Перегруппируем члены:

$$ (1 + h\beta_2)y_i + (\alpha_1 + h\beta_1)y_{i-1} + (\alpha_0 + h\beta_0)y_{i-2} = 0 $$

Для определения коэффициентов $\alpha_1, \alpha_0, \beta_2, \beta_1, \beta_0$ разложим $y_{i-1}$, $y_{i-2}$ и их производные в ряд Тейлора в окрестности точки $x_i$ и приравняем коэффициенты при степенях $h$ к нулю, чтобы получить максимальный порядок точности.

Разложения в ряд Тейлора:
- $y_{i-1} = y_i - hy'_i + \frac{h^2}{2}y''_i - \frac{h^3}{6}y'''_i + \frac{h^4}{24}y''''_i - O(h^5)$
- $y_{i-2} = y_i - 2hy'_i + 2h^2y''_i - \frac{4h^3}{3}y'''_i + \frac{2h^4}{3}y''''_i - O(h^5)$
- $y'_{i-1} = y'_i - hy''_i + \frac{h^2}{2}y'''_i - \frac{h^3}{6}y''''_i + O(h^4)$
- $y'_{i-2} = y'_i - 2hy''_i + 2h^2y'''_i - \frac{4h^3}{3}y''''_i + O(h^4)$

Подставляем эти разложения в исходное уравнение метода и группируем коэффициенты при $y_i$ и ее производных:

- $h^0: 1 + \alpha_1 + \alpha_0 = 0$
- $h^1: -(\alpha_1 + 2\alpha_0) - (\beta_2 + \beta_1 + \beta_0) = 0$
- $h^2: (\frac{\alpha_1}{2} + 2\alpha_0) - (-\beta_1 - 2\beta_0) = 0$
- $h^3: -(\frac{\alpha_1}{6} + \frac{4\alpha_0}{3}) - (\frac{\beta_1}{2} + 2\beta_0) = 0$
- $h^4: (\frac{\alpha_1}{24} + \frac{2\alpha_0}{3}) - (-\frac{\beta_1}{6} - \frac{4\beta_0}{3}) = 0$

Для получения конкретной схемы нужно задать некоторые коэффициенты. Выберем $\alpha_1 = 0$. Тогда система упрощается:
- $1 + \alpha_0 = 0 \implies \alpha_0 = -1$

Подставляем $\alpha_1=0, \alpha_0=-1$ в остальные уравнения:
- $2 - (\beta_2 + \beta_1 + \beta_0) = 0$
- $-2 - (-\beta_1 - 2\beta_0) = 0 \implies \beta_1 + 2\beta_0 = 2$
- $\frac{4}{3} - (\frac{\beta_1}{2} + 2\beta_0) = 0 \implies \beta_1 + 4\beta_0 = \frac{8}{3}$

Решая систему для $\beta_1, \beta_0$:
- $( \beta_1 + 4\beta_0) - (\beta_1 + 2\beta_0) = \frac{8}{3} - 2 \implies 2\beta_0 = \frac{2}{3} \implies \beta_0 = \frac{1}{3}$
- $\beta_1 = 2 - 2\beta_0 = 2 - \frac{2}{3} = \frac{4}{3}$

Теперь находим $\beta_2$:
- $\beta_2 = 2 - \beta_1 - \beta_0 = 2 - \frac{4}{3} - \frac{1}{3} = 2 - \frac{5}{3} = \frac{1}{3}$

Итак, мы получили коэффициенты:
$\alpha_1 = 0, \alpha_0 = -1, \beta_2 = 1/3, \beta_1 = 4/3, \beta_0 = 1/3$.

Подставляем их в уравнение `(2)`:
$$ (1 + \frac{h}{3})y_i + (0 + \frac{4h}{3})y_{i-1} + (-1 + \frac{h}{3})y_{i-2} = 0 $$
$$ (1 + \frac{h}{3})y_i + \frac{4h}{3}y_{i-1} + (\frac{h}{3} - 1)y_{i-2} = 0 $$

Умножим все на 3, чтобы избавиться от дробей:
$$ (3+h)y_i + 4h y_{i-1} - (3-h)y_{i-2} = 0 $$
Что и является искомой формулой.

### 2. Вывод стартовой формулы 3-го порядка

Для того чтобы основная схема 4-го порядка работала корректно, нужно "разогнать" ее с помощью стартовой формулы, которая вычисляет $y_1$ с достаточно высокой точностью.

#### Подход через неявную схему Рунге-Кутты

Будем искать стартовую формулу в виде неявной одношаговой схемы:
$$ y_1 = y_0 + h \cdot \Phi(y_0, y_1, h) $$

Для уравнения $y' = f(y) = -y$ рассмотрим схему вида:
$$ y_1 = y_0 + h(\alpha f(y_0) + \beta f(y_1)) $$
$$ y_1 = y_0 + h(-\alpha y_0 - \beta y_1) $$
$$ y_1 + h\beta y_1 = y_0 - h\alpha y_0 $$
$$ y_1(1 + h\beta) = y_0(1 - h\alpha) $$
$$ y_1 = y_0 \frac{1 - h\alpha}{1 + h\beta} $$

Разложим точное решение в ряд Тейлора в точке $x_0$:
$$ y(x_0 + h) = y_0 + hy'_0 + \frac{h^2}{2}y''_0 + \frac{h^3}{6}y'''_0 + \frac{h^4}{24}y^{(4)}_0 + O(h^5) $$

Для уравнения $y' = -y$ имеем:
- $y'_0 = -y_0$
- $y''_0 = -y'_0 = y_0$
- $y'''_0 = -y''_0 = -y_0$
- $y^{(4)}_0 = y'''_0 = y_0$

Подставляем:
$$ y(x_0 + h) = y_0(1 - h + \frac{h^2}{2} - \frac{h^3}{6} + \frac{h^4}{24} + O(h^5)) $$

Теперь разложим нашу численную формулу:
$$ y_1 = y_0 \frac{1 - h\alpha}{1 + h\beta} = y_0(1 - h\alpha)(1 + h\beta)^{-1} $$

Используем разложение $(1 + x)^{-1} = 1 - x + x^2 - x^3 + x^4 + O(x^5)$:
$$ (1 + h\beta)^{-1} = 1 - h\beta + h^2\beta^2 - h^3\beta^3 + h^4\beta^4 + O(h^5) $$

Перемножаем:
$$ y_1 = y_0(1 - h\alpha)(1 - h\beta + h^2\beta^2 - h^3\beta^3 + h^4\beta^4 + O(h^5)) $$
$$ y_1 = y_0[1 - h(\alpha + \beta) + h^2(\alpha\beta + \beta^2) - h^3(\alpha\beta^2 + \beta^3) + h^4(\alpha\beta^3 + \beta^4) + O(h^5)] $$

Приравниваем коэффициенты при степенях $h$:
- $h^0$: $1 = 1$ ✓
- $h^1$: $-(\alpha + \beta) = -1$ → $\alpha + \beta = 1$
- $h^2$: $\alpha\beta + \beta^2 = \frac{1}{2}$
- $h^3$: $-(\alpha\beta^2 + \beta^3) = -\frac{1}{6}$ → $\alpha\beta^2 + \beta^3 = \frac{1}{6}$
- $h^4$: $\alpha\beta^3 + \beta^4 = \frac{1}{24}$

Из первого уравнения: $\alpha = 1 - \beta$.

Подставляем во второе уравнение:
$$ (1-\beta)\beta + \beta^2 = \frac{1}{2} $$
$$ \beta - \beta^2 + \beta^2 = \frac{1}{2} $$
$$ \beta = \frac{1}{2} $$

Следовательно, $\alpha = 1 - \frac{1}{2} = \frac{1}{2}$.

Проверим третье уравнение:
$$ \frac{1}{2} \cdot \frac{1}{4} + \frac{1}{8} = \frac{1}{8} + \frac{1}{8} = \frac{1}{4} \neq \frac{1}{6} $$

Схема с $\alpha = \beta = 1/2$ (метод трапеций) дает только 2-й порядок точности.

#### Правильный вывод для 3-го порядка

Для достижения 3-го порядка точности используем формулу вида:
$$ y_1 = y_0 \frac{P(h)}{Q(h)} $$

где $P(h)$ и $Q(h)$ - многочлены от $h$. Подберем их так, чтобы разложение совпадало с точным решением до члена $O(h^3)$ включительно.

Пусть $P(h) = 1 + p_1 h + p_2 h^2 + p_3 h^3$ и $Q(h) = 1 + q_1 h + q_2 h^2 + q_3 h^3$.

Разложим $\frac{P(h)}{Q(h)} = P(h) \cdot Q(h)^{-1}$ и приравняем к точному решению $1 - h + \frac{h^2}{2} - \frac{h^3}{6}$.

После решения системы уравнений (приравнивая коэффициенты при $h^0, h^1, h^2, h^3$) получаем:
$$ P(h) = 1 - h + \frac{h^2}{3} $$
$$ Q(h) = 1 + \frac{h^2}{3} $$

То есть:
$$ y_1 = y_0 \frac{1 - h + \frac{h^2}{3}}{1 + \frac{h^2}{3}} = y_0 \frac{3 - 3h + h^2}{3 + h^2} $$

С учетом начального условия $y_0 = -1$:
$$ y_1 = -\frac{3 - 3h + h^2}{3 + h^2} = \frac{-3 + 3h - h^2}{3 + h^2} $$

Или в эквивалентной форме:
$$ y_1 = \frac{h^2 - 3h + 3}{h^2 + 3} \cdot (-1) = \frac{-(h^2 - 3h + 3)}{h^2 + 3} $$

Можно также записать как:
$$ y_1 = \frac{3h - h^2 - 3}{h^2 + 3} $$

**Эта формула обеспечивает 3-й порядок точности** и позволяет основной схеме 4-го порядка работать с полной точностью.
